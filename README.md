# Telegram FAQ-бот

Бот читает вопросы и ответы из коллекции `boxes` в Cloud Firestore.
Каждый документ содержит:

- `question` — текст вопроса;
- `answer` — текст ответа.

Поместите ключ сервисного аккаунта Firebase в `serviceAccount.json` в рабочей директории. Аккаунту нужен доступ на чтение Firestore. Не публикуйте ключ и токен бота.

```sh
export BOT_TOKEN='ваш токен BotFather'
go run .
```

Команда `/start` и обычные сообщения показывают приветствие с кнопками вопросов. При нажатии бот заново читает данные из Firestore и отправляет актуальный ответ. Изменения данных не требуют перезапуска бота.

## Docker

Установите и запустите Docker с поддержкой Docker Compose. В папке проекта создайте файл `.env`:

```sh
cp .env.example .env
```

Замените значение `BOT_TOKEN` в `.env` на токен BotFather. Рядом с `compose.yaml` должен лежать `serviceAccount.json`. Файл ключа подключается только для чтения при запуске и не попадает в образ.

```sh
docker compose up -d --build
```

Проверка состояния: `docker compose ps`. Остановка: `docker compose down`. После изменения кода снова выполните `docker compose up -d --build`. Открывать порты не требуется: бот получает сообщения через long polling.
